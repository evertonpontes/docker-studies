# Docker Studies

This is a collection of projects built to practice programming concepts, exploring `Docker` technology.

## Projects

- Basic Dockerfile — A basic project that build a Docker image and when is run, it print "Hello, Captain!" to the console before exiting. **Challenge:** [Basic Dockerfile](https://roadmap.sh/projects/basic-dockerfile) **Project:** [basic-dockerfile](basic-dockerfile).

- Portfolio with nginx — A simple static portfolio website created as a **Docker learning project**. [portfolio-with-nginx](portfolio-with-nginx).

- Node API — A simple REST API built with **Node.js and Express** as a Docker study project. [node-api](node-api).
